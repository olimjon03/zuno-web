# Edit profile fields

Edit profile exposes display name, email, profile photo and the current neighborhood with a Change neighborhood shortcut. Country/region selects are shown only in the dedicated neighborhood mode. The editor remains mounted while visiting that mode so unsaved name/email drafts survive returning. Existing page styles and other screens are unchanged.

Save profile updates only display_name through a verified-user server action; stale/forged neighborhood and email fields are ignored. Change neighborhood continues updating only neighborhood_id. The plus button below the profile image opens the photo picker and uploads the selected image through the existing authenticated route. A failed upload keeps the chosen file for Retry. These independent controls avoid presenting an email-confirmation request as a completed profile/database update.

Change email calls authenticated Supabase Auth updateUser, with the existing trusted /auth/callback redirect. Pending confirmation leaves the verified current address visible. A successful immediate change is reflected only if Auth returns the requested email. Invalid, signed-out and rate-limited requests return useful errors. The token-hash confirmation route now also accepts email_change with a fixed Settings redirect; ordinary email confirmation behavior is preserved. Provider settings determine the actual confirmation flow; see [Supabase updateUser](https://supabase.com/docs/reference/javascript/auth-updateuser).

Validation: lint, TypeScript/production build and all 51 Node tests pass. Tests cover name-only writes, authenticated email requests, trusted redirects, pending/confirmed state, validation/rate limits and email-change OTP confirmation. Isolated Playwright verified no Country select in Edit profile, name/email/photo controls, neighborhood round-trip without draft loss, pending email confirmation with unchanged current address, photo upload, name-only save preserving the changed area, reload persistence and 390px layout. Hosted email delivery/confirmation and actual mobile hardware were not tested. No SQL migration, dependency, configuration or stylesheet changes are needed.


Avatar control follow-up: the profile image in Settings has a teal plus button at its bottom center. It opens the native image picker and uploads after selection; the old separate picker/Save photo section is removed. Invalid files leave the existing avatar untouched, upload failures retain the selected file for Retry, and duplicate requests are locked while pending. Existing 110px desktop / 90px mobile avatar dimensions are preserved with styles local to this control. Native picker opening, auto upload, invalid-type handling, failure/retry, teal badge placement and 390/1440px layouts were checked in Playwright; lint, build and the existing 51 tests pass.
